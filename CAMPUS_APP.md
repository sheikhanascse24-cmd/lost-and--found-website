# New Campus Lost N Found application

The Vercel-compatible application is in `campus-app/`.

The existing PHP files, MySQL setup and user uploads remain intact in this folder. Run the new application separately with `start-campus-app.ps1`, or follow `campus-app/README.md`.

The public source belongs in this repository. The live application is https://campus-lost-n-found-gamma.vercel.app. Configure `campus-app` as the root directory when connecting the repository to Vercel.
