# The Absolute Simplest Guide - 4 Steps to Run Your Website

## 🎯 That's It. Just 4 Steps.

---

## **STEP 1: Create Two Folders** ⏱️ 1 minute

**Go to:** `C:\xampp\htdocs\lost_and_found_web\`

**Create these folders:**
- `uploads`
- `uploads\profiles`

**Done? ✅ Move to Step 2**

---

## **STEP 2: Start Apache & MySQL** ⏱️ 1 minute

**Open XAMPP Control Panel**

```
Search for "XAMPP Control Panel" in Start Menu
↓
Open it
↓
Click "Start" next to Apache (should turn green)
↓
Click "Start" next to MySQL (should turn green)
↓
Wait 5 seconds for both to show "Running"
```

**Done? ✅ Move to Step 3**

---

## **STEP 3: Open Browser & Visit Website** ⏱️ 30 seconds

**Open any web browser (Chrome, Firefox, Edge)**

**Type in address bar:**
```
http://localhost/lost_and_found_web/
```

**Press Enter**

**You should see the Home Page with buttons:**
- Register
- Login
- Find Items
- Post Item

**Done? ✅ Move to Step 4**

---

## **STEP 4: Test the Website** ⏱️ 2 minutes

**Do this:**

1. Click **"Register"**
   - Fill: Name, Email, Password
   - Click Register

2. Click **"Login"**
   - Enter your Email & Password
   - Click Login

3. Click **"Post Item"**
   - Fill: Type (Lost/Found), Title, Description
   - Click Post Item

4. Click **"Find Items"**
   - See your item in Twitter-like feed
   - Try Comment & Claim buttons

**Done? ✅ Your website is running!**

## 🆘 If Something Doesn't Work

### **"Cannot reach localhost"**
→ Go back to Step 2, click Start on Apache again

### **"Cannot connect to database"**
→ Go back to Step 2, click Start on MySQL again

### **"Cannot upload images"**
→ Go back to Step 1, make sure folders exist

### **"Blank/White page"**
→ Press F12, check if there are red errors
→ Press Ctrl+Shift+Delete to clear cache
→ Reload page

### **"Still not working"**
→ Read **START_HERE.md** for more details
→ Restart your computer
→ Try again
